# Keyboard Shortcuts

## Files and tabs

| Shortcut | What it does |
|---|---|
| ⌘N | New document |
| ⌘O | Open a file |
| ⌘S | Save |
| ⇧⌘S | Save As |
| ⌘P | Print |
| ⌘W | Close the tab |
| ⇧⌘W | Close the window |
| ⌘Q | Quit Kertas |
| ⌘, | Settings |
| ⇧⌘] or ⌃⇥ | Next tab |
| ⇧⌘[ or ⌃⇧⇥ | Previous tab |
| ⌘1 … ⌘9 | Go to tab 1 to 9 |
