# Kertas

Version {version}

Kertas is a Markdown editor where reading and editing happen in the same place. Everything is shown rendered, and the block you're working on shows its Markdown.

## The name

*Kertas* is the Indonesian and Malay word for paper. It comes from Arabic *qirṭās*, which comes from Greek *chartēs*, a sheet of papyrus. English *chart* and *charter* share that root, and so does Swahili *karatasi*.
