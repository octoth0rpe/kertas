## Text size

| Shortcut | What it does |
|---|---|
| ⌘+ or ⌘= | Zoom in |
| ⌘- | Zoom out |
| ⌘0 | Reset zoom |

## Moving around

| Shortcut | What it does |
|---|---|
| ← → | Previous or next character |
| ↑ ↓ | Previous or next line |
| ⌥← ⌥→ | Previous or next word |
| ⌘← ⌘→, Home End | Start or end of the line |
| ⌘↑ ⌘↓ | Start or end of the document |
| Page Up, Page Down | Scroll by a page |
| ⌥↑ ⌥↓ | Previous or next block |
| Esc | Finish editing |

## Selecting

Add ⇧ to any movement to select as you go.

| Shortcut | What it does |
|---|---|
| ⇧← ⇧→ | Select by character |
| ⇧↑ ⇧↓ | Select by line |
| ⌥⇧← ⌥⇧→ | Select by word |
| ⇧⌘← ⇧⌘→, ⇧Home ⇧End | Select to the start or end of the line |
| ⇧⌘↑ ⇧⌘↓ | Select to the start or end of the document |
| ⌥⇧↑ ⌥⇧↓ | Select by block |
| ⌘A | Select all |

## Editing

| Shortcut | What it does |
|---|---|
| ↩ | New line. Continues lists and quotes; on an empty item, ends the list. Press it twice to start a new paragraph. |
| ⇧↩ | Line break within a paragraph or list item |
| ⇥ ⇧⇥ | Indent or outdent a list item, or code |
| ⌘] ⌘[ | Indent or outdent lines |
| ⌥⇥ | Insert a tab |
| ⌫ or ⇧⌫ | Delete the previous character |
| ⌦ | Delete the next character |
| ⌥⌫ ⌥⌦ | Delete the previous or next word |
| ⌘⌫ | Delete to the start of the line |
| ⌘X ⌘C ⌘V | Cut, copy and paste |
| ⌘Z | Undo |
| ⇧⌘Z | Redo |

## Finding

| Shortcut | What it does |
|---|---|
| ⌘F | Find: opens the find bar |
| ⌥⌘F | Find and Replace. In the replacement, ↩ replaces the match and goes to the next. |
| ⌘G ⇧⌘G | Next or previous match. In the find bar, ↩ and ⇧↩ do the same. |
| ⌘E | Use the selection for Find |
| Esc | In the find bar, close it, leaving the match selected |
| ⌃⌘Space | In the find bar, show Emoji & Symbols |

## Buttons and Settings

| Shortcut | What it does |
|---|---|
| ⇥ ⇧⇥ | When no block is being edited, move between the document and the buttons in its bars. In Settings, move between the controls. |
| Space | Press the button or control that has the focus |
| ↩ | In Settings, Done |
| Esc | In Settings, close it |
