# Bundled spelling dictionaries

Hunspell dictionaries from SCOWL 2020.12.07 (http://wordlist.sourceforge.net), as packaged by wooorm/dictionaries (https://github.com/wooorm/dictionaries):

- `en-US`: en_US, from `dictionaries/en`.
- `en-GB`: en_GB-ise, from `dictionaries/en-GB`.

MIT AND BSD; the notice is in the Licenses document (scripts/acknowledgements.hbs). Check a dictionary's license before adding it: many, under the GPL, can't ship with Kertas. Users can add any dictionary to their settings folder instead.
